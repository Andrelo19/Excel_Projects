# 🥙 Kebab Sales Analysis

## 📊 Project Overview

This project analyzes sales data from a Kebab business using Microsoft Excel.

The objective is to transform raw sales data into meaningful business information through data cleaning, analysis, visualization, and dashboard development.

## 🎯 Business Objectives

- Analyze overall sales performance.
- Identify the best-performing products.
- Analyze sales trends.
- Identify relevant business KPIs.
- Provide insights that can support business decision-making.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Data Visualization
- Dashboard Development
- Business Analysis

## 📈 Analysis

The project includes analysis of sales performance and business metrics using Excel tools such as pivot tables, formulas, charts, and interactive elements.

## 💡 Key Insights

Key findings and business insights will be documented based on the results obtained from the analysis.
